# IDP Report Compile Note

Use `IDP_Report.tex` as the source for the updated project report.

The file `IDP_Report.pdf` in this folder is the original template PDF unless you recompile the TeX source. Do not submit the old PDF.

Recommended compile flow in Overleaf:

1. Upload the full `Project-Report-Template-main` folder.
2. Set `IDP_Report.tex` as the main file.
3. Compile with pdfLaTeX.
4. Run BibTeX if references do not appear automatically.
5. Compile twice more so the table of contents, figures, tables and bibliography update.

Current report scope:

- Chapter 1: Introduction
- Chapter 2: Theory and Fundamentals
- Chapter 3: System Design and Methodology
- Chapter 4: Implementation

Chapters 5 and 6 are intentionally not included.
