## Slide Claims

### Safe Claim

The Phase 2 system completes the data-to-spike-to-PWL pipeline and validates LIF neuron behavior at circuit level. Dataset-scale evaluation using LIF-derived features preserves IDS detection performance while producing a sparse event-driven representation.

### Do Not Claim

The full Cadence hardware array achieved 99.20% accuracy.

### Correct Accuracy Claim

The LIF-derived software pipeline achieved 99.20% accuracy on balanced Normal-vs-Attack detection, while the Cadence LIF waveform provides circuit-level support for the neuron behavior.
